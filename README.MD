# The Button Game

A simple-looking button game that gets harder as you play.

## 🎮 How to Play

The game gives you a random command, such as:

* **CLICK**
* **DON'T CLICK**
* **CLICK TWICE**
* **CLICK 3 TIMES**
* **WAIT**
* **CLICK WHEN GREEN**
* **CLICK WHEN RED**
* **CLICK TWICE WHEN GREEN**
* **CLICK ONCE WHEN RED**
* **WAIT 2 SECONDS**

Follow the command correctly to increase your score and move to the next round.

As the rounds increase, more difficult commands become available.

If you make a mistake, your score resets to 0.

## 💻 Technologies

The game is built using:

* HTML
* CSS
* JavaScript

Everything is contained in a single HTML file, so it can run directly in a browser.

## 📦 Shrink

This project was made for **Hack Club Shrink**, where the goal is to make projects as small as possible.

The main challenge wasn't just making the game work — it was making it work while keeping the file size below the limit.

## 🚀 Goal

The goal was to see how much functionality I could fit into a tiny browser game while still keeping it playable and fun.
